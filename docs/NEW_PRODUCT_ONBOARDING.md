# New Product Onboarding Guide
*How to bring a new repo into the ASC Agent Platform*

## Step 1: Prepare the Repository
Ensure the repository is under the `ASC-Creative` GitHub organization.

## Step 2: Add the "Maps"
Create three markdown files in the root of the new repo. Use the **MeetingGenius** ones as templates:
1.  **`AGENT.md`**: Define what the agent can and CANNOT touch for this product.
2.  **`CODEBASE.md`**: Describe the folder structure and key API endpoints.
3.  **`ARCHITECTURE.md`**: List the tech stack and integration points.

## Step 3: Create Mattermost Channel
1.  Create a new channel named `#[product]-dev` (e.g., `#janus-dev`).
2.  Add the bot user to this channel.
3.  Find the Channel ID and add it to the `PRODUCT_CHANNEL_MAP` in `modules/mattermostNotifier.js`.

## Step 4: Verify
1.  Restart the `ASC Agent Service`.
2.  Post a test task brief in `#agent-intake` for the new product.
3.  Verify that the agent acknowledges the task and opening a Draft PR in the new channel.
